# Playery releases

Downloads for [Playery](https://www.sialk.net/playery), the player for the
wall: add a film or a folder of stills, put them in order, press Take, and
nothing but the picture reaches the projector. Opening hours, a phone
remote, subtitles from a file. For galleries, installations, degree shows
and the back room of a venue.

**Download, for Apple silicon and Intel:** https://www.sialk.net/playery

**What it plays, and what to do with a file it does not:** https://www.sialk.net/playery/formats

**Every release, with what changed:** https://www.sialk.net/playery/releases

Free keeps three playlists of three files; bought once, £49, it has no
limit and every update.

Playery was called Sialk Player until October 2026. Builds before 1.0.1
carry the old name, and from 1.0.1 each release also carries its files
under the old names, so older links keep working.

This repository holds release files and nothing else. The application is
not open source. Playery is made by [Sialk LTD](https://www.sialk.net),
London, which also makes [Operatour](https://www.sialk.net/operatour), the
live-visuals application.

## Verify a download

```
shasum -a 256 Playery-macOS.dmg
shasum -a 256 Playery-macOS-Intel.dmg
```

Checksums for each release are listed on its release page.
