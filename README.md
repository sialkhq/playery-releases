# Sialk Player — releases

Downloads for [Sialk Player](https://www.sialk.net/player), the player for
the wall: add a film or a folder of stills, put them in order, press Play,
and nothing but the picture reaches the projector. Opening hours, a phone
remote, subtitles from a file. For galleries, installations, degree shows
and the back room of a venue.

**Get the beta, and how to open it:** https://www.sialk.net/player

**What it plays, and what to do with a file it does not:** https://www.sialk.net/player/formats

This repository holds release files and nothing else. The application is
not open source. Sialk Player is made by [Sialk](https://www.sialk.net),
London, which also makes [Sialk Operator](https://www.sialk.net/operator),
the live-visuals application.

## Verify a download

```
shasum -a 256 Sialk-Player-beta-macOS.zip
```

Checksums for each release are listed on its release page.
